## 📋 项目简介

面向中小学班主任和电教老师，一站式解决**学生/小组管理**、**积分卡发放核销**、**教室一体机管控**三件事。

系统由两套程序组成：

| 程序 | 装在哪 | 干什么 |
|---|---|---|
| **教师端**（管理端） | 老师的电脑 | 学生名单、小组分配与换座、积分生成/核销、监控、叫号、一体机控制、投屏 |
| **一体机端**（班级设备） | 教室的一体机 | 托盘常驻，提供摄像头画面、屏幕直播、麦克风对讲、语音播报、全屏叫号动画、投屏接收 |

两端通过**局域网**直连：不需要服务器、不需要公网、不依赖云服务，数据全部留在本机。

## ✨ 能力总览

### 控制台

打开就是一张总览：学生数（男女）、小组数、在线一体机、积分卡已核销/待核销、今日核销数量；
右侧是**一体机状态面板**（在线/离线、摄像头、麦克风、帧率，每 10 秒自动刷新）、**最近操作**、**系统信息**。

### 学生与小组

- 👥 **学生名单** — 导入 Excel / CSV，表头自动识别；手动添加、行内编辑、拖动排序、批量删除
- 🔒 **删除保护** — 一次删掉超过总人数 1/3 时要求输入管理员口令
- 🧩 **小组分配** — 编辑模式下拖动学生进组/出组，新建或删除小组，整页一次保存
- 🪑 **小组换座** — 给每个小组打分数，自动按分数排序；小组做成方块自由拖进座位；
  「布局设置」里可以随意摆放座位位置，支持**投屏到一体机**（排名 / 座位两种画面）

### 积分卡

- 🔐 **双重防伪** — 10 位唯一编号 + SHA-256 哈希，每台设备独立加盐
- 📦 **批量生成** — 一键导出 A4 排版 Word，3 列 × 7 行裁剪即用
- 🏷️ **Code128 条码** — 兼容常见扫码枪，扫一下自动提交核销
- 🔍 **防重复核销** — 条件更新 + rowcount 判定，同一张卡只能核一次
- 🛡️ **盐值轮转** — 恢复出厂时重新生成加密盐，所有旧卡立即失效

### 班级设备

- 🖥️ **设备管理** — 填 IP + 访问密钥，或用「一键配置码」自动填好全部参数
- 📹 **班级监控** — 每台一体机一路实时画面（UDP），卡片大小自动对齐
- 🎙️ **双向对讲** — 老师说话进教室音箱，同时能听到教室声音
- 🔈 **收听开关** — 单独控制是否收听教室麦克风
- 📣 **班级叫号** — 选中学生 → 选话术 → 一体机弹出**全屏蓝色动画**并语音播报，播完自动收起
- 🎛️ **一体机控制** — 运行状态、屏幕直播、关机/重启/打开网址、**终端式远程指令**

## 🏗️ 架构

```
┌──────────────────────────────┐        ┌──────────────────────────┐
│  教师端（老师电脑）            │        │  一体机端（教室一体机）     │
│                              │  TCP   │                          │
│  class-manager.exe           │ 3457   │  class-manager-kiosk.exe │
│  ├─ WinForms + WebView2 外壳  │ ─────▶ │  ├─ 托盘常驻，HTTP 服务    │
│  └─ 本地后端 127.0.0.1:3445   │ ◀───── │  ├─ 摄像头 / 屏幕 / 麦克风 │
│                              │  UDP   │  ├─ 语音播报（SAPI）       │
│  页面：控制台 / 学生 / 小组    │ 3457   │  ├─ 全屏叫号动画 / 投屏    │
│        监控 / 叫号 / 积分     │        │  └─ 远程指令（白名单）     │
└──────────────────────────────┘        └──────────────────────────┘
                                    视频帧（UDP 分片推流）
```

- **页面永远在本机**：教师端窗口加载 `http://127.0.0.1:3445`，浏览器按「安全上下文」处理，对讲麦克风权限不会被拦
- **视频走 UDP**：摄像头帧分片推送，走 TCP 只会浪费带宽
- **其余接口走 TCP**：状态、设置、播报、指令、投屏、音频

## 🚀 安装

### 老师端

```powershell
dist\class-manager-setup.exe
```

安装程序会：选目录 → 释放程序（含内置 Python 运行时，不用另装）→ 建快捷方式 → 可选开机自启 → 写卸载登记。
装完双击启动，首次进入需要设置管理员口令。

### 一体机端

```powershell
dist\class-manager-kiosk-setup-v1.0.exe
```

安装界面（WebView2）：

- 安装位置可手填，也可点「选择文件夹…」
- 默认装到**非系统盘**（有 D 盘就是 `D:\ClassManager-Kiosk`），普通用户即可写入
- 三个选项：**开机自动启动**、**创建桌面快捷方式**、**清除本机已有配置（恢复出厂）**
- 安装包**不携带任何密码/密钥**；勾选「清除」后本机旧的访问密码、设备名会被清空，装完是全新设备

也支持静默安装（机房批处理）：

```powershell
class-manager-kiosk-setup-v1.0.exe --silent --dir "D:\ClassManager-Kiosk"
```

首次运行：托盘图标 → 打开设置 → 设置访问密码 → 填教室名称 → 选摄像头。

### 把一体机接进教师端

1. 一体机端 →「设备信息」复制**局域网地址 + 访问密钥**，或点「生成配置码」
2. 教师端 →「设置 → 班级设备 → 添加设备」→ 粘贴配置码，自动填好 IP / 端口 / 密钥
3. 点「测试连接」，显示「连接成功 / 密钥校验通过」
4. 打开「班级监控」，卡片变成**在线**、有画面就通了

### 端口与防火墙

| 端口 | 协议 | 在哪台机器 | 用途 |
|---|---|---|---|
| 3445 | TCP | 教师端 | 桌面版内置后端（仅本机） |
| 3457 | TCP | 一体机端 | HTTP 接口（状态 / 播报 / 指令 / 音频 / 投屏） |
| 3457 | UDP | 一体机端 | 摄像头视频流 |

一体机必须放行入站 **TCP + UDP 3457**（首次启动弹窗点「允许」，或手动加防火墙规则）。

## 🖥️ 使用说明

### 控制台

顶部一排数字：学生总数、小组数、在线一体机、积分卡、今日核销。
下面左列是**一体机状态**（每台一张卡，10 秒自动刷新）和**快捷入口**；
右列是**最近操作**（登录、保存分组、完整性告警等，事件名已中文化）和**系统信息**。

### 学生名单

1. 「导入」选择 Excel(.xlsx) / CSV，表头识别「姓名 / 性别 / 学号」等列
2. 表格里可直接改姓名、性别、学号；左侧 ⠿ 拖动调整顺序
3. 勾选多行可批量删除；一次删除超过总人数 1/3 时会要求输入管理员口令

### 小组分配

- 默认**只读**，点「编辑」后按钮变成「保存」
- 编辑态可以拖动学生进组/出组、改组名、新建小组、删除小组（组里的学生自动回到未分组）
- 改完点「保存」一次性写库；不保存直接刷新就是放弃修改

### 小组换座

1. **① 打分数** — 每个小组输一个分数，失焦自动按分数从高到低重排，第一名金色高亮
2. **② 拖进座位** — 小组做成方块，拖进座位格；座位之间可互换，拖回待放区即取消
3. **布局设置** — 座位方块可以随意拖动到画布任意位置，想怎么摆就怎么摆（位置本地保存）
4. **展示排名 / 展示座位** — 一体机全屏显示排行榜或座位表；之后改分数、拖座位**实时同步**，不用反复点

### 班级叫号

选中学生 → 选话术（去老师办公室 / 家长在校门口 / 交作业 / 完全自定义）→ 一体机全屏弹出蓝色动画并播报。

播报体验：

- 全屏蓝色圆盘从中心撑满屏幕，中间显示播报内容，播完自动收回消失
- 播报前后可选提示音（客舱广播三种，默认低沉版），播报时自动调系统音量、播完还原
- 语速在「播报设置」弹窗里调；「停止播报」可随时打断并收起画面

### 班级监控

- 每台设备一张卡片：实时画面、在线状态、帧率、已收帧数
- 🎙️ **麦克风** 开始对讲（变红闪烁），同时自动开启收听
- 🔈 **喇叭** 单独开关「听教室声音」
- ⛶ **全屏** 放大画面，全屏下也能对讲

### 一体机控制

顶部下拉选设备，下面依次是：

- **运行状态**：设备名、摄像头、麦克风、远程执行授权、UDP 帧率
- **远程设置**：测试播报、一体机设置（远程改播报/音量/画质等）
- **屏幕直播**：点一下开始，一体机桌面实时画面
- **关机 / 重启 / 打开网址**：都需要二次确认
- **远程指令**：像命令行一样逐条执行，`> 命令` + 真实换行输出 + 红字错误 + 退出码

> ⚠️ 摄像头开关、麦克风开关、远程执行授权 **只能在一体机本机操作**，管理端不提供远程入口（接口层也已拦截）。

### 操作日志

控制台「查看全部」或设置页「查看操作日志」进入：

- 事件名中文显示（登录 / 保存分组 / 完整性告警…）
- 按严重程度着色：删除类、完整性告警黄色，登录失败、核销失败红色
- 表头固定、区域内滚动，支持搜索过滤，看不到旧记录时点「返回控制台」

## 🔒 安全设计

| 机制 | 说明 |
|---|---|
| 管理员口令 | PBKDF2-SHA256（20 万轮加盐），旧版明文登录时自动升级 |
| 会话 | 64 字符随机 Session ID + HttpOnly Cookie，空闲 8 小时过期 |
| CSRF | 双提交令牌，所有 POST 校验 |
| 登录节流 | 同一 IP 连续 5 次失败锁定 5 分钟 |
| 一体机访问密钥 | 32 位随机密钥，机器对接用，可一键重置 |
| 一体机访问密码 | 打开设置界面要密码；关窗口即退出登录，重新打开需再登录 |
| 远程执行 | 默认关闭，必须在本机授权；支持命令白名单 + 超时强杀 |
| 核销防双花 | 条件更新（`WHERE status='未使用'`）+ rowcount 判定 |
| 文件保护 | 中间件拦截敏感路径；下载仅限导出目录内的 `.docx` |
| 配置完整性 | 启动时校验 `data` 下配置/设备/批次的 SHA-256（签名密钥由 Windows DPAPI 封装），被外部改动会在设置页提示并记入 `data/audit.log` |
| 目录权限 | 启动时把 `data` 目录 ACL 收紧为「当前用户 / SYSTEM / Administrators」 |
| 操作日志 | 登录、登录失败、改口令、导入旧数据、检测到配置被改都会写 `data/audit.log`，可在页面查看 |
| 一体机进程保护 | 一体机端给自己加「拒绝终止」规则，任务管理器 / `taskkill /F` 会被拒绝，只能从托盘「退出」正常关闭 |

### ⚠️ 使用提醒：请保护好自己的电脑

本项目是**本地运行的开源软件**，数据就放在本机的 `data` 目录里，安全性最终取决于**这台电脑本身的安全**。

- **务必给 Windows 账号设置开机密码**，不要与他人共用同一个账号
- 离开座位请锁屏（`Win + L`），不要让电脑长时间处于已登录的无人状态
- 管理员口令建议 **10 位以上、大小写+数字+符号混合**；短口令在拿到配置文件后可被离线暴力破解
- 多人共用一台电脑时，建议给每位老师单独一个 Windows 账号（`data` 目录权限会自动收紧到当前账号）
- 别人若以**你的账号**运行程序，仍可能改动数据；系统会在下次启动时提示「配置文件被外部修改」，并可查看操作日志追溯

源码完全公开，任何人都能看到实现细节；但没有这台电脑的登录权限，就无法改动本机数据。**保护好自己的电脑，就是保护数据。**

## 🗑️ 卸载

| 程序 | 卸载方式 | 会清掉什么 |
|---|---|---|
| 教师端 | 安装目录里的 `uninstall.exe`，或设置 →「应用」 | 先结束进程（含后端 python）→ 删快捷方式 / 自启 / 注册表 → 删程序目录；可选保留 `data` |
| 一体机端 | 安装目录里的 `uninstall.exe`，或设置 →「应用」 | 结束进程（含进程保护）→ 删快捷方式 / 两条自启项 / 卸载登记 / 厂商根键 → 删程序目录 → 清 `%LOCALAPPDATA%\ClassManager-KioskAgent`（访问密码、设备名、密钥、日志、WebView2 缓存）→ 清临时文件 |

两者都支持静默卸载：

```powershell
uninstall.exe --dir "D:\ClassManager-Kiosk" --silent
```

> 卸载前一定会先结束对应进程；如果进程退不干净会直接报错，**不会带着进程删文件导致半删状态**。

## ❓ 常见问题

**一体机重启后监控没画面？**
管理端的 UDP 收帧线程不会因 ICMP 不可达退出，一体机回来后几秒内自动恢复。

**画面卡但语音正常？**
UDP 视频在弱网/无线下容易丢片，优先让一体机走有线；帧率可在 1~30 调整。

**对讲点不动 / 提示麦克风不可用？**
请用教师端桌面版（页面是 127.0.0.1）。用浏览器打开非 https 的局域网地址时，浏览器禁止采集麦克风。

**一体机端关掉窗口后还要重新输密码？**
这是设计如此：关窗口即退出登录。

**一体机端在任务管理器里结束不掉？**
v1.0 起加了进程保护，这是正常现象。请用托盘图标右键「退出」（会先解除保护）。

**叫号只有声音没有画面？**
一体机端窗口被其它全屏程序挡住时可能看不到动画；关掉全屏程序或按 Esc 收起。

**检查更新提示「仓库还没有发布版本」？**
GitHub 仓库还没有发布 Release。发一个带 `update` 字样 zip 附件的 Release 即可，见 [docs/release.md](docs/release.md)。

**一体机端连不上？**
检查三件事：同一局域网（含 AP 隔离）、防火墙放行 TCP+UDP 3457、IP 是否固定。
