# 安装程序待办（做打包时必须自动配置的事）

> 记录时间：2026-11-09
> 用途：下次写 `installer/` 或 `build/` 脚本时，按这份清单把配置做进安装流程，不留给用户手动配。

---

## 一、一体机端安装包（class-manager-kiosk）

### 1. 防火墙：必须自动放行（最容易漏）

一体机要给老师电脑提供服务，安装时就要把入站规则建好，否则「连不上」会变成部署期最大的坑。

- 放行**按程序**（不是按端口），勾选 **TCP + UDP**，网络类型选 **专用 + 公用**
- 建议在安装器里用 `netsh` 或 `New-NetFirewallRule` 建规则，卸载时同步删除
- 规则名统一，例如 `class-manager-kiosk`
- 端口以配置里的为准（默认 3457），用户改端口时规则要跟着改

参考命令（安装时执行一次）：

```bat
netsh advfirewall firewall add rule name="class-manager-kiosk" dir=in action=allow ^
    program="<安装目录>\class-manager-kiosk.exe" protocol=any profile=any enable=yes
```

卸载时删除：

```bat
netsh advfirewall firewall delete rule name="class-manager-kiosk"
```

### 2. 端口与配置文件

- 安装后预置 `%LOCALAPPDATA%\ClassManager-KioskAgent\config.json`：
  - `Port` = 3457（默认），`VideoPort` = 0（跟 TCP 同号）
  - `BindAddress` = 0.0.0.0
- 如果安装器允许改端口，**必须同步改防火墙规则**

### 3. 开机自启（可选勾选）

- 勾选与否写注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
- 值名 `ClassManagerKioskAgent`，内容 `"<安装目录>\class-manager-kiosk.exe" --tray`
- 界面里已有开关，安装器只要初值一致即可（二选一，别打架）

### 4. 安装目录

- 默认装到普通目录（如 `D:\class-manager-kiosk`）
- **不要装进** `C:\Program Files` 之类需要提权的目录：摄像头/麦克风在受限完整性下会打不开
- 安装后不要停留在「Low 完整性」目录（沙箱/安全软件保护目录），否则采集设备失败

### 5. 首次使用引导

- 首次启动 → 托盘图标 + 气泡提示
- 打开主界面时若未设密码，进「初始化访问密码」流程（已有）
- 引导里提示：复制「一键配置码」或「对接信息」给教师端

## 二、管理端安装包（class-manager）

**部署模型已定：不做服务器集中部署。** 每个老师一台机器装桌面版，一体机装在教室里，走局域网。安装器只做「教师机桌面版」这一种形态，不需要选模式、不需要配 https。

### 教师机桌面版（唯一形态）

- 安装桌面版，自带后端，只监听 `127.0.0.1:3445`
- 页面永远是本机地址 → 浏览器允许麦克风 → **对讲、监听都正常**
- 安装器可勾选「开机自启」（桌面版已有此开关）
- 装完填一体机 IP + 访问密钥即可

> ⚠️ 不要改成「浏览器打开别的机器上的后端」：`http://<局域网 IP>` 属于非安全上下文，
> 浏览器会直接禁用麦克风，对讲就废了。这条是硬约束，安装器不提供该选项。

### 异地 / 跨网访问：只加内网穿透

老师不在学校、或管理端要访问校外的一体机时，**不引入服务器**，用内网穿透/VPN 打通道即可：

| 方式 | 放在哪一侧 | 说明 |
|---|---|---|
| frp / ngrok 等端口映射 | **一体机侧**（推荐） | 把 3457 映射到外网，老师端仍用本机桌面版填映射地址；麦克风不受影响 |
| ZeroTier / Tailscale 组虚拟局域网 | 两端 | 老师电脑和一体机加入同一虚拟网段，直接填虚拟 IP，最省心 |
| 花生壳等 | 一体机侧 | 同上，注意同时映射 TCP（接口）和 UDP（视频） |

注意点：
- **隧道要覆盖 TCP 与 UDP 3457**，只映射 TCP 会导致视频没画面、只剩接口可用
- 一体机端保持默认 `BindAddress=0.0.0.0`，不要绑 127.0.0.1，否则穿透工具连不进来
- 穿透工具一般不支持 UDP，遇到这种情况：视频会缺失，但状态/对讲/播报仍可用（可接受降级）

## 三、部署检查清单（可以做成安装器最后的「自检」页）

| 检查项 | 判定方式 |
|---|---|
| 一体机端口可达 | 管理端「测试连接」通过，返回设备名与版本 |
| 防火墙已放行 | 同上；或安装器自检 `netsh advfirewall firewall show rule name=...` |
| UDP 视频正常 | 班级监控卡片状态「在线」且有画面、帧率 > 0 |
| 麦克风可用 | 页面是 127.0.0.1（桌面版默认）；点麦克风图标能开始采集 |
| 一体机 IP 固定 | 建议在路由器做 DHCP 静态绑定，否则重启换 IP 会失联 |
| AP 隔离 | 无线环境下同网段设备要能互访（部分 AP 默认隔离客户端） |
