# 更新日志

## v1.1（2026-11-18）

### 修复：与旧版「班级积分管理系统」同时安装会串台

两个程序的桌面端**首选端口都是 3445**，而判断「这个端口上是不是自己的后端」的依据又只有
登录页里的一个通用样式类 `auth-card`，于是出现下面这种情况：

```
先开 班级积分管理系统 → 占住 3445
再开 班级管理系统     → 探测 3445，看到登录页有 auth-card
                     → 判定"这是我自己的后端"，直接复用
                     → 窗口里显示的其实是班级积分管理系统的界面
```

反过来也一样：先开班级管理系统，后开的班级积分管理系统会显示成班级管理系统的界面。
因为是同一套模板，两边都认不出对方；点「学生名单」「小组换座」这些功能会全部消失，
看起来像功能丢了、数据没了。

**这次两处一起改：**

| 改动 | 说明 |
|---|---|
| 教师端后端端口 3445 → **3480** | 与旧程序彻底分开；3480 被占时仍在 3481–3509 内顺延（不会碰到一体机的 3457） |
| 复用判断加产品指纹 | 不再只看 `auth-card`，改为匹配登录页里的 `data-app="class-manager"`；旧程序没有这个标记，不会被误认 |

结果：

- 两个程序可以同时安装、同时启动，各跑各的后端，互不串台
- 「上次没退干净就复用已有后端」这个便利仍然保留（只对本产品生效）

实测：

```
3480 被"别的程序"（有 auth-card、无 data-app）占用
  → 班级管理系统没有复用，自动起在 3481          ✓

3480 上是班级管理系统自己的后端（有 data-app）
  → 日志：backend reuse: 已有实例在 3480，不重复起   ✓

教师端 3480 + 一体机端 3457 同时运行
  → 各自响应正常                                  ✓
```

## v1.0（2026-11-10）

首个正式版本。

- **控制台**：学生/小组/一体机/积分卡总览，一体机状态面板每 10 秒刷新，最近操作、系统信息
- **学生名单**：Excel/CSV 导入，行内编辑，拖动排序，批量删除（超 1/3 需管理员口令）
- **小组分配**：编辑模式下拖动学生进出小组，新建/改名/删除小组，整页一次保存
- **小组换座**：给小组打分自动排序，方块拖进座位，布局可自由摆放，支持投屏（排名/座位）
- **班级叫号**：全屏蓝色动画 + 语音播报 + 提示音 + 播报时自动调音量，播完自动收起
- **班级监控**：实时画面、双向对讲、收听开关、全屏
- **一体机控制**：运行状态、屏幕直播、关机/重启/打开网址、终端式远程指令
- **积分卡**：批量生成 A4 Word、扫码核销、防重复核销
- **安装**：教师端 / 一体机端各一套安装程序，一体机端默认装非系统盘、可静默安装
- **卸载**：两端独立卸载程序，卸载前强制结束进程，一体机端会清掉配置、缓存、注册表
- **安全**：进程保护（任务管理器结束不掉）、配置完整性校验、操作日志、目录 ACL 收紧
